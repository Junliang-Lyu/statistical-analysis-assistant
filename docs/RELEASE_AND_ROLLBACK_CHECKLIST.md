# 统计助手发布包、验收与回滚清单

本文件只描述待批准操作。本次未部署、未发布、未操作 DNS 或密钥。

## 发布包

外层：`stats-release-<ID>.tar.gz` + 对应 `.sha256`。压缩包内只有 `<ID>/` 下五个文件，当前拉取器严格核验该集合：

| 文件 | 用途 |
| --- | --- |
| stats-api-<ID>.tar | 本地或 CI 测试过的 Docker 镜像；服务器仅 docker load |
| compose.stats.yaml | 独立统计服务运行配置，无构建指令/主机端口 |
| stats.caddy | 已审核站点规则的副本；不会自动替换共享网关 |
| check-release.sh | 无付费调用的基本线上检查 |
| release.txt | 可校验的版本标识 |

一次性 bootstrap 独立交付：deploy/server/ 中的拉取器、安装脚本、service/timer；本地提案补丁仅供主站审查，不塞进上述五文件包。所有 .env、密钥、原始上传数据、.git、本地虚拟环境、课堂文档均不进入镜像或包。公网模型 key 只配置在 /opt/stats/.env.production。

本次 compose 改为 external 网络后，需要重新测试/构建发布包；旧包校验通过不代表它包含新配置。本次按照用户限制不生成或发布新版 Release。

## 上线前（本地）

- [ ] 测试、四方法镜像 HTTP 冒烟通过；模型离线测试不得表述为真实模型可靠性。
- [ ] Compose config 使用纯占位值，不加载真实环境文件；统计没有主机 ports，external stats_edge 正确。
- [ ] 主站基础配置提案 + 原投资 override 合并后，Caddy 同时保留主站挂载、投资挂载、统计目录及全部网络。
- [ ] Caddy 配置可解析；保存三站配置基线及已知健康 URL。
- [ ] 包 SHA-256、文件白名单、镜像标签、非 root 用户、无秘密文件均符合要求。

## 上线验收（需另行确认）

- [ ] 现有主站 HTTPS、/en/、原 API 及原限制检查仍通过。
- [ ] 现有投资 /lab 和 /api/health、版本号保持预期；不更改投资数据或镜像。
- [ ] stats HTTPS、首页、JS/CSS、CSV 下载、/api/health、/release.txt 与目标版本一致；容器 healthy、无 OOM。
- [ ] 四种统计方法数值正确；真实 DeepSeek 调用成功，不显示凭据或原始错误。
- [ ] 解释型追问复用统计结果；年份筛选重新诊断/计算；另一浏览器不能访问会话。
- [ ] 错误 Origin / Host、过大 CSV、预算/配额耗尽及模型超时均有明确失败反馈；失败不显示成功。
- [ ] 重启统计服务后预算/配额保留，会话允许丢失并清楚提示。
- [ ] 独立统计停止后主站和投资仍可访问；共享网络和预算卷不被删除。
- [ ] 配置层面确认投资发布的原两文件命令包含统计接入；共享 Caddy 重建后统计入口保留。生产重建/投资发布不在本次授权内。

## 回滚

- [ ] 应用失败：选上一个已验证统计镜像和 compose，使用固定 project stats，只更新 stats-api；保留 stats_budget 卷与 external stats_edge。
- [ ] 更新失败且没有旧版本：停止 stats-api，报告不可用；不要删除卷，不执行其他项目 down。
- [ ] 当前拉取器 switch() 健康检查只尝试一次；首次 TLS 申请可能暂时失败，因此先完成网关/TLS验收，再启用自动安装。若需重试策略应另做小改动和测试。
- [ ] 私有凭据/价格不回滚为包内值；预算历史不清空。应用会话重启后失效是已知行为。
- [ ] 网关改动失败：恢复事先备份的主站两个公共配置，校验后只重建 Caddy；恢复主站/投资通行。统计可暂时下线。
- [ ] 已接入后的常规主站回滚应使用含统计桥接配置的旧版本；直接回滚到接入前版本会移除统计入口。不得把“应用回滚”和“网关接入撤销”混在一起。
- [ ] 回滚后再次检查三站、版本号及预算持久化；记录结果，不把脚本退出成功当成浏览器端验收。
